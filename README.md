# Изъятка — сайт-каталог

Статический сайт, дублирующий карточки из Telegram-канала «Изъятая техника лизинговых компаний».
Никакого сервера не нужно: это одна HTML-страница плюс папка с фото.

```
izyatka/
├── index.html      ← сам сайт (внутри — каталог в блоке <script id="catalog">)
├── sync.js         ← бот-синхронизатор: тянет новые посты из канала
├── images/<id>/    ← фото позиций: 1.jpg, 2.jpg, …
└── README.md
```

---

## 1. Публикация на Netlify (5 минут, бесплатно)

1. Зайдите на **netlify.com** → *Add new site* → *Deploy manually*.
2. Перетащите папку `izyatka` целиком в окно браузера.
3. Готово — сайт по адресу вида `izyatka-abc123.netlify.app`.
   Имя меняется в *Site configuration → Change site name* (например `izyatka`).
4. Свой домен (`izyatka.ru`) прикручивается позже в *Domain management*.

**Форма заявки** работает сразу: Netlify Forms ловит отправки без бэкенда.
Заявки видны в *Forms* в панели Netlify. Чтобы они падали на почту — *Forms → Notifications → Email*.

### Альтернатива: GitHub Pages

Создайте репозиторий, загрузите файлы, в *Settings → Pages* выберите ветку `main`, папку `/`.
Учтите: на GitHub Pages **форма заявки работать не будет** (нет обработчика), останется только кнопка «Написать в Telegram».

## 2. Автосинхронизация с каналом

### Шаг 1. Создать бота

1. В Telegram напишите **@BotFather** → `/newbot`.
2. Придумайте имя и username (например `izyatka_sync_bot`).
3. BotFather пришлёт **токен** вида `7123456789:AAF...`. Сохраните его.

### Шаг 2. Добавить бота в канал

Канал «Изъятка» → *Управление* → *Администраторы* → *Добавить администратора* → найдите своего бота.
Права можно оставить минимальные, главное — чтобы он был администратором: только так бот видит посты канала.

### Шаг 3. Запускать синхронизацию

Нужен Node.js 18 или новее (`node -v` для проверки).

```bash
cd путь/к/izyatka
BOT_TOKEN=7123456789:AAF... node sync.js
```

Скрипт заберёт новые посты, разложит по полям, скачает фото в `images/` и допишет каталог
прямо в `index.html`. После этого заново перетащите папку на Netlify — сайт обновится.

**По расписанию** (macOS/Linux, каждые 10 минут):

```
*/10 * * * * cd /Users/вы/izyatka && BOT_TOKEN=7123... /usr/local/bin/node sync.js >> sync.log 2>&1
```

### Важное ограничение

Telegram Bot API отдаёт **только те посты, что вышли после добавления бота в канал**.
Семь уже опубликованных карточек внесены в каталог вручную — их тексты на месте,
а фото нужно один раз доложить руками в `images/<id>/`:

| id папки | позиция |
|---|---|
| `jac-n90-ref` | Рефрижератор JAC N90 |
| `bomag-bw203` | Каток BOMAG BW 203 ADO-4 |
| `paz-320405` | Городской автобус ПАЗ 320405 |
| `politrans-94171` | Полуприцеп-сортиментовоз ПОЛИТРАНС 94171-011 |
| `kran-kk10` | Кран козловой КК-10 |
| `lovol-td1304` | Трактор Lovol TD1304 |
| `haval-dargo` | HAVAL Dargo (фото уже лежат) |

Кладите файлы как `1.jpg`, `2.jpg`, `3.jpg` — первый становится обложкой карточки.
Если фото нет, карточка не ломается: показывается аккуратная плашка с категорией.

## 3. Формат поста, который бот понимает

Тот же, что вы публикуете сейчас:

```
🔻 Рефрижератор JAC N90

Цена в лизинг: 4 417 500 ₽ с НДС
Цена без лизинга: 4 800 000 ₽ с НДС      ← необязательно
Год: 2022 · Пробег: 3 445 км
Двигатель: 3.8 л, 152 л.с., дизель
Город: Москва

Текст описания…

Изъятая техника лизинговой компании.
Быстро оформлю в лизинг, аванс и срок подберу под Ваш оборот.

Пишите → @vse_v_lizing

#jac #рефрижератор #изъятка
```

Категория определяется по хештегам: `#каток`, `#автобус`, `#трактор`, `#полуприцеп`,
`#кран`, `#авто` и т.д. Список ключей — в `sync.js`, блок `CAT`, дополняется одной строкой.

Пост без строки «Цена в лизинг» бот пропускает — обычные сообщения в канале каталог не засоряют.

---

## 4. Правка вручную

Каталог лежит прямо в `index.html` — блок `<script id="catalog" type="application/json">`.
Это обычный JSON: можно поправить цену, убрать проданную позицию, изменить текст.
`sync.js` этот блок уважает и только дописывает новые карточки сверху.
